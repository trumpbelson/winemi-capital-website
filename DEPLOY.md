# Deploy WINEMI CAPITAL. website

## Option A — Vercel (recommended)

1. Push this repo to GitHub (already done for trumpbelson/winemi-capital-website).
2. Open https://vercel.com/new
3. Import `trumpbelson/winemi-capital-website`
4. Framework: **Other** (static)
5. Build command: leave empty
6. Output directory: `.`
7. Deploy

Live URL: `https://winemi-capital-website.vercel.app` (or your project URL)

## Option B — GitHub Pages

1. Repo → Settings → Pages → Source: Deploy from branch `main` / root
2. Site: `https://trumpbelson.github.io/winemi-capital-website/`
